# Fallout New Vegas Unofficial Patch (YUP): What It Fixes

The Yukichigai Unofficial Patch, or YUP, is a bug-fix compilation for Fallout: New Vegas. Its Nexus Mods page describes it as addressing bugs and exploits that the final official patch did not fix. If you follow the Viva New Vegas guide, YUP is part of its base install, so you do not choose it separately. This post explains what it does, how it relates to Unofficial Patch NVSE Plus, and one known issue between the two.

*Checked October 28, 2026 against the Nexus Mods pages for YUP, Unofficial Patch NVSE Plus and a YUP fix mod, PC Gamer's New Vegas guide and the Fallout Wiki. These are mod authors' own descriptions, and we did not test anything in the game.*

## What YUP is

According to its [Nexus Mods page](https://www.nexusmods.com/newvegas/mods/51664), YUP is an unofficial patch that addresses many bugs, exploits and similar issues in Fallout: New Vegas that the last official patch left alone. The page says it can run on a fresh install without installing anything else. The [Fallout Wiki](https://fallout.wiki/wiki/Mod:Yukichigai_Unofficial_Patch) calls it a standalone unofficial patch that is largely included in the Tale of Two Wastelands mod.

## Where it goes in the load order

The YUP page says to load it at the top of your load order, directly below the standard game files, and that doing so should not cause conflicts. It adds that the Pre-Order Packs and Courier's Stash must load before YUP for its fixes to apply, and that it has not heard of mods having problems with YUP as long as they load after it.

## YUP and Unofficial Patch NVSE Plus

YUP's own page lists fixes it could not include for technical reasons, naming JIP LN NVSE, JohnnyGuitar NVSE and Unofficial Patch NVSE Plus. The [Unofficial Patch NVSE Plus page](https://www.nexusmods.com/newvegas/mods/71239) describes a collection of mostly NVSE-based bug fixes meant to be used alongside YUP. It combines and updates fixes from the earlier Unofficial Patch NVSE and Unofficial Patch Plus. Its description says to load it high in your load order, after YUP, that it requires all official DLC except Courier's Stash, and that fixes it once carried were removed because YUP version 12.1 and later include them.

## A known issue between the two

A separate Nexus mod, [YUP Disabled Creature Spawn Fix](https://www.nexusmods.com/newvegas/mods/97600), describes a major error in YUP: an old fix for the Explosion Immunity bug that can leave many creature spawn points permanently disabled. Its author says Unofficial Patch NVSE Plus fixes the problem for new saves, and that this mod repairs existing saves. The page says the error was not yet fixed inside YUP itself when it was written. We do not know whether a newer YUP has fixed it, so check the YUP page for its current version notes.

## If you use Viva New Vegas

[PC Gamer's New Vegas guide](https://www.pcgamer.com/fallout-new-vegas-guide-tips-best-experience/) names both Yukichigai Unofficial Patch and Unofficial Patch NVSE Plus among the key mods of the most basic Viva New Vegas install. The guide manages the order for you, so follow its steps rather than adding either mod by hand. Our [modding guide](https://frontbuffer.net/gaming/fallout-series_guide/) explains what Viva New Vegas is, and it is the safer starting point if you want these fixes.

## What we could not confirm

- YUP's current version and whether it still has the spawn-point problem.
- Whether Viva New Vegas has changed which of these mods it installs. We did not open the guide's Bug Fixes page for this post.
- How either patch affects an existing save, beyond what the mod authors say.
