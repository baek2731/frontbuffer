Each storefront shows only its own library, so a collection spread across Steam, Epic, Xbox and PlayStation has no single view. Two PC tools try to combine them: GOG Galaxy 2.0 and Playnite. Both help, but neither covers every platform, and much of GOG Galaxy's coverage depends on community plug-ins.

*Checked October 20, 2026 against a community-maintained integration list for GOG Galaxy 2.0, PC Gamer's 2019 coverage and Kotaku's Playnite page. Integrations break and change, so confirm what your tool supports today. We did not test either app.*

---

## GOG Galaxy 2.0

A [community integration list](https://github.com/Mixaill/awesome-gog-galaxy) shows only two official integrations, Epic Games Store and Xbox. Steam, Battle.net and PlayStation Network are community plug-ins. The same list shows that the PSN plug-in brings in the library and achievements but not install and launch, while Steam's plug-in handles library, install and launch, achievements and game time. [PC Gamer](https://www.pcgamer.com/gogs-quest-to-unite-all-game-launchers-just-might-work-and-microsoft-is-already-on-board/) reported in 2019 that GOG Galaxy 2.0 itself is not open source, only the community-made plug-ins are.

Community plug-ins can break when a platform changes, so check the plug-in's status before you rely on it.

---

## Playnite

[Kotaku's Playnite page](https://kotaku.com/download/playnite) describes it as a free, open-source game library manager under the MIT license, focused on Windows. It lists Steam, Epic, GOG, EA App, Battle.net, Ubisoft Connect, Xbox PC, itch.io, Amazon Games and Humble, and says it supports emulators, plug-ins and manual installs, with no paid tiers.

---

## What neither tool covers well

We found no integration that reads a Nintendo eShop library, and the PlayStation plug-in is a community one that does not install or launch games. For consoles, expect to add games by hand or use a spreadsheet.

---

## What to track yourself

- **Which edition you own on which platform.** A note such as "base game only" or "complete edition" saves a mistaken repurchase.
- **Whether a game supports cross-save.** This varies by game, so check each game's own support page before buying a second copy.
- **Status.** Tag games as playing, completed or backlog so a large library stays usable.


---

## A practical start

Pick one tool and connect your accounts. Playnite is the open-source option and GOG Galaxy 2.0 is the one with an official Xbox and Epic integration. Tag the games you are actively playing first, and leave the rest for later.
